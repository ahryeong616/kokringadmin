# 리뷰 이벤트 배너 (상세페이지 최상단)

이젠오토 리뷰 이벤트 상세페이지 맨 위에 들어가는 배너의 **조판 소스**입니다.
AI로 그린 그림이 아니라 HTML/CSS로 조판한 뒤 브라우저로 캡처하는 방식이라,
로고·모델 사진·한글 문구가 전부 원본 그대로 손상 없이 출력됩니다.

## 디자인

흰 배경에 중앙 정렬, 대형 타이포, 점선 구분선, 번호 안내 리스트로 구성한
담백한 레이아웃입니다. 색은 브랜드 블루(`#1668B0`)와 별의 골드(`#FFC93C`)
두 가지만 쓰고 나머지는 무채색으로 눌러 정보가 먼저 읽히게 했습니다.

```
모델 원형 배지 → 로고 → 채널 라벨 → ★★★★★
→ 사진 한 장이면 / 후기가 돈이 됩니다 / REVIEW EVENT
→ ┈┈┈ 점선 ┈┈┈
→ 핵심 안내 문구 → 리워드 3단 → 참여처 1·2·3 → 주의사항
```

## 결과물 규격

| 항목 | 값 |
|---|---|
| 조판 기준 폭 | 860px (상세페이지 표준) |
| 실제 출력 크기 | **1720 × 2074px** (2배 해상도) |
| 파일 | `banner.png` |

## 만드는 법

원본 이미지 2개를 이 폴더에 넣고 스크립트를 실행합니다.

```bash
# 이 폴더에 아래 두 파일을 둔다
#   logo.png    - EGEN AUTO 로고 원본 (여백이 넓어도 자동으로 잘라냄)
#   model.png   - 모델 캐릭터 시트 원본
./build.sh
```

`build.sh`가 순서대로 처리합니다.

1. Pretendard 폰트 설치 (없을 때만)
2. 로고 여백 자동 제거 → `assets/logo_trim.png`
3. 모델 시트에서 얼굴을 정사각으로 크롭 → `assets/model_face.png`
4. 헤드리스 Chrome으로 2배 해상도 캡처 → `banner.png`

## 수정할 때

**문구·금액만 바꾼다면** `banner.html`의 `<div class="page">` 안쪽 텍스트만
고치고 `./build.sh`를 다시 실행하면 됩니다.

**모델 컷을 다른 것으로 바꾸려면** `build.sh` 안의 `crop((101, 40, 481, 420))`
좌표를 원하는 컷의 좌표로 바꾸면 됩니다. 캐릭터 시트의 컷별 위치는 다음과 같습니다.

| 영역 | y 범위 |
|---|---|
| 상단 히어로 상반신 컷 (현재 여기서 얼굴만 사용) | 29 ~ 508 |
| 회전 5컷 | 527 ~ 690 |
| 표정 5컷 | 701 ~ 881 |
| 전신 컷 | 883 ~ 1263 |

원형 배지 안에서 얼굴 위치가 어긋나면 `banner.html`의 `.face` 규칙에 있는
`object-position: 50% 42%` 값을 조절하세요. 두 번째 숫자가 작을수록 위로 올라갑니다.

## 주의

큰 글씨에는 `white-space:nowrap`이 걸려 있어 줄바꿈 없이 옆으로 삐져나갑니다.
문구를 길게 바꿨다면 결과 이미지를 눈으로 확인하세요.
본문 가용 폭은 **720px**(860 − 좌우 여백 70×2)입니다.

현재 각 문구의 실제 렌더 폭입니다.

- `사진 한 장이면` — 187px
- `후기가 돈이 됩니다` — 431px
- `REVIEW EVENT` — 351px
- 참여처 리스트 최대 — 243px
