# 리뷰 이벤트 배너 (상세페이지 최상단)

이젠오토 리뷰 이벤트 상세페이지 맨 위에 들어가는 배너의 **조판 소스**입니다.
AI로 그린 그림이 아니라 HTML/CSS로 조판한 뒤 브라우저로 캡처하는 방식이라,
로고·모델 사진·한글 문구가 전부 원본 그대로 손상 없이 출력됩니다.

## 결과물 규격

| 항목 | 값 |
|---|---|
| 조판 기준 폭 | 860px (상세페이지 표준) |
| 실제 출력 크기 | **1720 × 1849px** (2배 해상도) |
| 파일 | `banner.png` |

## 만드는 법

원본 이미지 2개를 이 폴더에 넣고 스크립트를 실행합니다.

```bash
# 이 폴더에 아래 두 파일을 둔다
#   logo.png    - EGEN AUTO 로고 원본 (여백이 넓어도 자동으로 잘라냄)
#   model.png   - 모델 캐릭터 시트 원본
./build.sh
```

`build.sh`가 순서대로 처리합니다.

1. Pretendard 폰트 설치 (없을 때만)
2. 로고 여백 자동 제거 → `assets/logo_trim.png`
3. 모델 시트에서 상반신 컷을 3:4로 크롭 → `assets/model_crop.png`
4. 헤드리스 Chrome으로 2배 해상도 캡처 → `banner.png`

## 수정할 때

**문구·금액만 바꾼다면** `banner.html`의 `<body>` 영역 텍스트만 고치고
`./build.sh`를 다시 실행하면 됩니다.

**모델 컷을 다른 것으로 바꾸려면** `build.sh` 안의 `crop((111, 29, 471, 509))`
좌표를 원하는 컷의 좌표로 바꾸면 됩니다. 캐릭터 시트의 컷별 위치는 다음과 같습니다.

| 영역 | y 범위 |
|---|---|
| 상단 히어로 상반신 컷 (현재 사용 중) | 29 ~ 508 |
| 회전 5컷 | 527 ~ 690 |
| 표정 5컷 | 701 ~ 881 |
| 전신 컷 | 883 ~ 1263 |

## 주의

글자를 늘리면 좌측 텍스트 컬럼(가용 폭 **462px**)을 넘칠 수 있습니다.
`banner.html`의 큰 글씨들은 `white-space:nowrap`이라 줄바꿈 없이 삐져나가므로,
문구를 길게 바꿨다면 결과 이미지를 눈으로 확인하거나 글자 크기를 함께 줄이세요.

현재 각 문구의 실제 렌더 폭은 다음과 같습니다.

- `사진 한 장이면` — 205px
- `후기가 돈이 됩니다` — 400px
- `15,150원` — 344px
