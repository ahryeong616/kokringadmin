# 상품 상세페이지

카페24 상품 상세설명에 그대로 붙여넣어 쓰는 HTML 파일 모음입니다.

## 파일

| 파일 | 상품 |
| --- | --- |
| `surfacer-gray-520ml.html` | 서페이서 회색 520ml (1액형 속건 프라이머 서페이서) |

## 적용 방법

1. 카페24 관리자 → **상품관리 → 상품수정 → 상세설명**
2. 에디터 우측 상단 **HTML(소스편집)** 버튼 클릭
3. 파일 내용 전체를 복사해서 붙여넣기
4. 저장 후 실제 상품 페이지에서 PC / 모바일 양쪽 확인

## 이미지 교체

파일 안에 `IMG-01` ~ `IMG-04` 로 표시된 회색 자리표시자 블록이 있습니다.
해당 `<div>` 를 통째로 아래 형태로 바꾸면 됩니다.

```html
<img src="이미지주소" alt="설명" style="display:block;width:100%;">
```

| 코드 | 들어갈 사진 | 권장 크기 |
| --- | --- | --- |
| IMG-01 | 제품 대표컷 (캔 정면 누끼) | 862 × 700px 이상 |
| IMG-02 | 패널에 도포하는 장면 | 862 × 620px 이상 |
| IMG-03 | 퍼티면 → 도포 후 비교컷 | 862 × 620px 이상 |
| IMG-04 | 작업 현장 · 사용 씬 | 862 × 620px 이상 |

이미지는 카페24 **웹FTP 또는 에디터 이미지 업로드**로 올린 뒤 주소를 복사해 사용합니다.

## 설계 메모

- 카페24 에디터가 `<style>` / `<link>` 태그를 제거하는 경우가 있어 **스타일을 100% 인라인**으로 작성했습니다.
- 미디어쿼리 없이 `clamp()` 와 `flex-wrap` 만으로 PC / 모바일 반응형을 처리합니다.
- 본문 폭은 카페24 상세페이지 표준인 **862px** 기준이며, 그보다 좁은 화면에서는 자동으로 줄어듭니다.
- 웹폰트(Gothic A1 / Archivo / IBM Plex Mono)가 차단되더라도 시스템 한글 폰트로 정상 표시됩니다.
- 단면 비교도, 도막 구조도, 도포 거리 안내도는 **인라인 SVG** 라 별도 이미지 업로드가 필요 없습니다.

## 확인이 필요한 수치

제품 설명서(`carpaintmenuer220119.pdf`)를 확인해 아래 값을 확정해야 합니다.
파일 안에서 `SPEC-CHECK` 주석으로 표시해 두었습니다.

- 건조 시간 / 연마 가능 시점 (현재 `20~30분`)
- 권장 도포 거리 (현재 `25~30cm`)
- 권장 작업 온도 (현재 `20~25℃`)
- 권장 도포 횟수 (현재 `2~3회`)
- 캔 1개당 도포 가능 면적 (현재 미기재)
