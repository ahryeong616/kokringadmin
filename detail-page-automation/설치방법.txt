콕링 상세페이지 자동 생성 - 설치 및 실행 방법

■ 준비물
  Node.js LTS  (https://nodejs.org 에서 설치, "다음"만 눌러도 됩니다)


■ 처음 한 번만 하는 일

  1) 최신 코드 받기
     D:\kokringadmin-main\kokringadmin-main 폴더에서 명령창을 열고
        git pull
     (git 을 안 쓰신다면 GitHub 에서 ZIP 을 받아 덮어쓰기 하셔도 됩니다.
      브랜치: claude/automation-system-program-93k1aq)

  2) 사진 준비
     graydoll 사진을 아래 폴더에 모아둡니다.
        D:\kokringadmin-main\kokring_shangpei\Grip+doll

     파일 이름 앞에 아래 글자를 붙이면 알맞은 자리에 자동 배치됩니다.
        hero_      대표컷        1장   (1번 커버, 5번 상단에 사용)
        front_     정면컷        1장   (3번 디테일)
        side_      옆모습        2장   (3번 디테일)
        closeup_   클로즈업      5장   (3번 디테일 캡션 카드)
        life_      사용 연출컷   4장   (4번 라이프스타일, 5번 하단)
        people_    착용/모델컷   2장   (5번 추천 대상)

     예) hero_01.jpg, front_01.jpg, side_01.jpg, closeup_band.jpg, life_bag.jpg

     ※ 이름을 안 붙여도 파일 순서대로 자동 배분되므로 그냥 넣어도 동작합니다.
     ※ 사진이 모자라면 있는 사진을 돌려 씁니다.


■ 매번 하는 일

  상세페이지_생성.bat 파일을 더블클릭합니다.  (그게 전부입니다)

  처음 실행할 때만 준비 작업으로 몇 분 걸리고, 그 다음부터는 20초 정도면 끝납니다.
  끝나면 결과 폴더가 자동으로 열립니다.

  저장 위치:  D:\kokringadmin-main\kokring_shangpei\graydoll\
  파일:       graydoll_1.png ~ graydoll_5.png


■ 5장의 구성

  1번  커버              대형 제품컷 + 영문 타이틀
  2번  문제 제기         "이런 경험 있으신가요?" + 브랜드 이야기
  3번  제품 디테일       FRONT / SIDE + 클로즈업 캡션
  4번  라이프스타일      사용 장면 + 선택하는 이유 4가지
  5번  선물/후기/FAQ     추천 대상 + 후기 + FAQ + 구매 버튼


■ 글 내용을 바꾸려면

  detail-page-automation\products\graydoll\product.json 을 메모장으로 열어
  글만 고치고 저장한 뒤, 다시 bat 파일을 더블클릭하면 됩니다.


■ 새 상품을 추가하려면

  1) products\graydoll 폴더를 통째로 복사해서 이름을 새 상품명으로 바꿉니다.
  2) 그 안의 images 폴더 사진을 새 상품 사진으로 교체합니다.
  3) product.json 의 글을 새 상품에 맞게 고칩니다.
  4) 상세페이지_생성.bat 을 메모장으로 열어 PRODUCT 값을 새 상품명으로 바꿉니다.

  상품이 여러 개 쌓이면 아래 명령으로 전부 한 번에 만들 수 있습니다.
        node generate.js --all --out "D:\kokringadmin-main\kokring_shangpei"


■ 자주 나는 문제

  "Node.js 가 설치되어 있지 않습니다"
      -> https://nodejs.org 에서 LTS 를 설치하고 PC 를 다시 시작해주세요.

  "프로젝트 폴더를 찾을 수 없습니다"
      -> 상세페이지_생성.bat 을 메모장으로 열어 맨 위 PROJECT 경로를
         실제 detail-page-automation 폴더 위치로 고쳐주세요.

  "사진 폴더를 찾을 수 없습니다"
      -> 같은 방법으로 IMAGES 경로를 실제 사진 폴더로 고쳐주세요.
